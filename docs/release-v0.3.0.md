# 败者食尘 v0.3.0

## 新功能

- 新增死亡拦截：原版防死遗物和药水完成判定后，角色仍会死亡时暂停死亡流程。
- 死亡时保留本局存档和节点快照，可直接选择“从本节点重来”。
- 选择“接受死亡并结束本局”时继续原版死亡、分数、历史记录及存档删除流程。
- 手机版与电脑版共用 `ModHelper` 公开战斗 Hook，不需要 BaseLib，也不增加 Android Harmony 原生跳板。

## 验证

- 电脑 v0.107.1 实际战斗验证：死亡窗口出现时死亡任务暂停且存档仍存在。
- 选择重来后恢复到节点初始战斗状态：角色存活、回合数为 1。
- 再次死亡选择放弃后，原版游戏结束界面正常出现，当前局存档正常删除。
- 手机 v0.103.2 与电脑 v0.107.1 均完成独立引用编译，0 警告、0 错误。
