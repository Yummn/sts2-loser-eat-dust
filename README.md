# 败者食尘（Loser Eat Dust）

这个 MOD 会在第一次进入地图节点时保存它的初始状态，让你在当前阶段内回到任何走过的节点重新选择。它不是简单地重试当前房间：已经记录的路线会保留下来，所以可以在多个旧节点之间切换。

从 v0.3.0 开始，它也会在正常的防死遗物和药水结算后拦住真正的死亡，让你选择从当前节点重来，或者接受死亡并继续原版结算。

## 使用方法

暂停菜单里会出现两个按钮：

1. “节点 X/Y：第 N 层 · 类型”用于循环选择已经走过的节点。
2. “败者食尘：从这里重来”用于载入该节点第一次进入时的状态。

每个坐标只记录第一次进入时的快照，不会被战斗结束、事件完成或中途保存覆盖。节点记录还会同步保存尖塔银行余额。MOD 只在单人模式生效，不依赖 BaseLib，也不包含 PCK。

## 安装

当前推荐版本为 [v0.3.0](https://github.com/Yummn/sts2-loser-eat-dust/releases/tag/v0.3.0)，支持 Android v0.103.2 和 PC v0.107.x。下载与平台匹配的 ZIP，解压后把完整的 `LoserEatDust` 文件夹放进游戏的 `mods` 目录。

## 实现参考

死亡拦截的交互思路参考了 Douvahkiin 的开源项目 [StS2-DeathIntercept](https://github.com/Douvahkiin/StS2-DeathIntercept)。本项目使用游戏公开的 `ModHelper` 战斗 Hook，并复用自己的节点快照恢复，不修改或删除原版存档函数。
